
# 10th K AI

Understand the concept. Recognize the pattern.
Solve with confidence.

## Problem

Class 10 students often know the subject but struggle
to understand textbook terminology and recognize
what type of question they are being asked.

## Solution

10th K AI is a textbook-grounded AI tutor for
Karnataka SSLC Class 10 students.

Question
   ↓
Textbook Retrieval
   ↓
Relevant Evidence
   ↓
AI Explanation
   ↓
Question Pattern
   ↓
Memory Trick
   ↓
Practice Question

## Features

- Textbook-grounded answers
- Subject filtering
- RAG search
- Question-pattern recognition
- Simple explanations
- Memory tricks
- Similar practice questions
- Textbook evidence with page number

## Tech Stack

- Python
- Streamlit
- FAISS
- Sentence Transformers
- Ollama
- Llama 3.2
- PyMuPDF

## Why I built it

I wanted to build something that could actually help
a Class 10 student study from their own textbooks.
